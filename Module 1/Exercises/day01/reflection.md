Reflection

1. What is the difference between Git and GitHub?
Git is a version control system that tracks changes to files on my computer. GitHub is an online platform where Git repositories can be stored, shared, and collaborated on.

 2. What is the purpose of the terminal?
The terminal allows users to interact with the computer by typing commands to create files, manage folders, and use tools like Git.

 3. What does git add do?
The git add command stages changes, preparing them to be included in the next commit.

 4. What is the purpose of git commit?
The git commit command saves the staged changes to the Git repository with a descriptive message.

 5. Write the daily Git workflow in the correct order.
1. Check repository status (git status)
2. Edit or create files
3. Stage changes (git add .)
4. Commit changes (git commit -m "message")
5. Push changes (git push)
